# Website images

Every image used by the website is in this single folder.

To change any image, simply **replace the file and keep the same filename** —
no HTML, CSS or JavaScript has to be edited.

| Filename | Where it is used |
| --- | --- |
| hero.jpg | Home page hero background |
| resort-main.jpg | Home about section, contact page hero |
| resort-exterior.jpg | About page hero, cancellation page hero |
| riverfront.jpg | Riverfront sections, privacy/terms hero |
| pool.jpg | Home contact section |
| poolside.jpg | Facilities page hero |
| deluxe-room.jpg, deluxe-room-2.jpg, deluxe-room-bathroom.jpg | Deluxe room card + room gallery |
| luxury-room.jpg, luxury-room-2.jpg, luxury-room-bathroom.jpg | Luxury room card + room gallery |
| wedding.jpg, party.jpg, celebration.jpg | Celebrations sections |
| gallery-01.jpg … gallery-06.jpg | Gallery page and home gallery preview |

Notes

- Room images are chosen in **Admin → Rooms** (filenames, comma separated).
- Gallery images are chosen in **Admin → Settings & Content** (filenames, comma separated).
- The files currently in this folder are clearly marked placeholders. Replace them
  with the resort's own photographs. Do not use photographs from other resorts.
- Recommended size: about 1600x900 px for the hero and 1200x800 px for the rest.
